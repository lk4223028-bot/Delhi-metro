# 🚇 Delhi Metro Route Planner (C++)

## 📌 Description
This project finds the shortest route between metro stations using Dijkstra Algorithm.

## ⚙️ Features
- Shortest path calculation
- Distance calculation
- Graph-based metro system
- Easy CLI interface

## 🛠️ Tech Used
- C++
- Data Structures (Graph)
- Dijkstra Algorithm

## ▶️ How to Run
g++ main.cpp MetroData.cpp RouteCalculator.cpp -o metro
./metro

## 📂 Project Structure
- main.cpp
- MetroData.cpp / .h
- RouteCalculator.cpp / .h
